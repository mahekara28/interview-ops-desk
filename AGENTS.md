# Interview Ops Desk

- Use the parent workspace's Mahek wrapper for Git/GitHub operations.
- Run `npm run check` and `npm run test:browser` before publishing changes.
- Keep demo and live interview records separate. Never imply a simulated receipt is a real email delivery.
- Greenhouse and Calendar adapters are read-only. MCP can inspect and propose; only the dashboard approves demo deliveries.
- Keep candidate data and credentials out of logs, screenshots, fixtures, and commits. Fixtures must be fictional.
- Scheduling and completion checks are deterministic. Draft approval is bound to the current evidence revision.
- Keep the UI usable on narrow screens and with a keyboard.
